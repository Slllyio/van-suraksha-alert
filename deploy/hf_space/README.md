# Van Suraksha (JwalaNetra)

India's first AI-driven forest fire Early Warning System for Guna Division, Madhya Pradesh.

- **LightGBM fire risk** (AUC 0.9991)
- **FIRMS NRT detection** (VIIRS/MODIS)
- **Canadian FWI** (Van Wagner 1987)
- **ABM ignition modeling** (tendu/mahua/grazier agents)
