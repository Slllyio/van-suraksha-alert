## Data Sources Used
- **Fire Detection:** NASA FIRMS VIIRS SNPP (Near Real-Time + Historical)
- **Fire Weather:** Canadian FWI System via NASA POWER / GFS reanalysis
- **Burn Scars:** IBM-NASA Prithvi-EO-2.0 Foundation Model + HLS Sentinel-2
- **Land Cover:** ESA WorldCover 2021 (10m resolution)
- **Terrain:** Copernicus DEM 30m (EU Space Programme)
- **Weather Forecast:** GFS 0.25 deg NWP via Herbie
- **Boundaries:** Guna Division GeoJSON (137 beats, 8 ranges)
- **3D Globe:** CesiumJS 1.95 with OpenStreetMap imagery
- **Fire Simulation:** Muhurta-2D PDE Engine (Rothermel elliptical spread model)
